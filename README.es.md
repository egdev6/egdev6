# Hola, soy Quique (egdev6) 👋

Senior Frontend Engineer enfocado en **flujos de desarrollo con IA**. Construyo software y comparto el proceso: frontend, arquitectura, testing, design systems e IA aplicada.

Soy mantenedor en [@Gentleman-Programming](https://github.com/Gentleman-Programming), una organización que construye infraestructura open source para agentes de código con IA, y coordino la comunidad de desarrollo [@Stack-and-Flow](https://github.com/Stack-and-Flow).

> 🔴 **En directo todos los miércoles a las 19:00 (Madrid)** en [Twitch](https://www.twitch.tv/egdev6/), construyendo en abierto. Una vez al mes, con invitado en *Charlando con…*. ¡Os esperamos!

## Ahora

_Actualizado en septiembre de 2026_

- 🎬 **Construyendo** — **particle-studio**: un editor visual, independiente del framework, para animaciones reutilizables en HTML Canvas, en desarrollo privado.
- 🤝 **Manteniendo** — [gentle-ai](https://github.com/Gentleman-Programming/gentle-ai): correcciones del estado de instalación del plugin de OpenCode.
- 🔧 **Mejorando** — [mobile-agent-orchestrator](https://github.com/egdev6/mobile-agent-orchestrator): una skill guiada de Pi para tener un entorno móvil de agentes de IA seguro y persistente.

## Dónde construyo

### Mantenedor — [@Gentleman-Programming](https://github.com/Gentleman-Programming)

Una organización que construye infraestructura de agentes para desarrolladores.

| Proyecto | Qué es | Mi parte |
| --- | --- | --- |
| [engram](https://github.com/Gentleman-Programming/engram) | Memoria persistente para agentes de código (Go, SQLite + FTS5, MCP) | APIs de store y servidor, TUI |
| [gentle-shell](https://github.com/Gentleman-Programming/gentle-shell) | Harness de Pi para flujos de agente con criterio de arquitecto | Superficies del shell, paneles de uso |
| [gentle-ai](https://github.com/Gentleman-Programming/gentle-ai) | Configuración de agentes, skills y flujos multi-agente para los asistentes de código que ya usas | Estado de instalación del plugin de OpenCode |

**[Mis pull requests fusionadas en la org →](https://github.com/search?q=is%3Apr+author%3Aegdev6+org%3AGentleman-Programming+is%3Amerged&type=pullrequests)**

Esto conecta con [engram-monitor](https://github.com/egdev6/engram-monitor), el dashboard de observabilidad que escribí para esa capa de memoria.

### Organizador — [@Stack-and-Flow](https://github.com/Stack-and-Flow)

Una comunidad de desarrollo donde construimos proyectos reales, exploramos la IA aplicada al trabajo diario y compartimos lo que aprendemos.

Nuestro proyecto insignia es el **[Stack & Flow Design System](https://github.com/Stack-and-Flow/design-system)**, un design system colaborativo pensado para escalar, ser accesible y usarse en proyectos reales.
