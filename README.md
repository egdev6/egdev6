# Hi, I'm Quique (egdev6) 👋

Senior Frontend Engineer focused on **AI-powered developer workflows**. I build software and share the process: frontend, architecture, testing, design systems and applied AI.

I'm a maintainer at [@Gentleman-Programming](https://github.com/Gentleman-Programming), an organization building open-source infrastructure for AI coding agents, and I run the [@Stack-and-Flow](https://github.com/Stack-and-Flow) developer community.

> 🔴 **Live every Wednesday at 19:00 (Madrid)** on [Twitch](https://www.twitch.tv/egdev6/), building in the open. Once a month there's a guest in *Charlando con…*.
